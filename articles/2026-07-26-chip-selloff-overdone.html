BlackRock: chip-stock rout is overdone, sees buying opportunity

Equities / Single Names · Friday, July 24, 2026
  • BlackRock strategists say Friday's memory-chip selloff — SanDisk, Micron, SK Hynix all down sharply — is overdone relative to fundamentals, per Benzinga.
  • The case: AI memory demand remains structurally strong, and each of these names is still up triple digits year-to-date despite the pullback (Micron +227% YTD, SanDisk +526% YTD).
  • The view frames the selloff as a valuation air-pocket after a blowout run rather than a change in the AI-infrastructure demand thesis.
  • This is a useful counterweight to the more bearish capex-skepticism narrative driving Alphabet and Tesla lower — not everyone reads the same data the same way.
  • For fund positioning: watch for dip-buying flows in memory names early next week as a tell on whether the "AI capex fear" trade has further to run.
Source: Benzinga.
